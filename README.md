# AUROCKS — сайт скалодрома

Прототип сайта боулдерингового скалодрома AUROCKS (Санкт-Петербург, открытие 15 января 2027).

**Посмотреть:** https://syetavozna.github.io/aurocks/

## Что внутри
- `index.html` — весь сайт в одном файле (HTML + CSS + JS), без сборки.
- Страницы: главная, Новичкам, Цены и абонементы, Расписание и запись, Тренеры, Акции и события, Праздники и корпоративы, Магазин, Контакты, Личный кабинет.
- Расписание, запись, личный кабинет и оплата — обёртки под виджеты 1С:Фитнес клуб.
- Карточки акций, тренеров, событий и товаров собираются из объекта `DATA` в начале скрипта — для маркетолога это единственное место для правок контента.

## Статус
Цены, адрес, телефон, имена тренеров — заглушки. Фото — плейсхолдеры до открытия.
